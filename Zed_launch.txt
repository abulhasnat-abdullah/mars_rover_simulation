Yes, you can launch the ZED 2i to provide only
point cloud and RGB data by disabling other features like odometry and IMU in the configuration parameters. This is typically done through the ZED SDK or the official ROS/ROS 2 wrappers by setting specific parameters in the launch or configuration files. 
In the ZED ROS/ROS 2 Wrapper
You need to modify the relevant YAML configuration file (e.g., zed2i.yaml or common_stereo.yaml) to disable the positional tracking and depth stabilization, which automatically enable the IMU and odometry. 

    Locate the configuration files: These are usually in the zed_wrapper/config directory of your ROS workspace.
    Modify the parameters: In the appropriate YAML file, set the following parameters to false or 0:
        pos_tracking.pos_tracking_enabled: false
        depth.depth_stabilization: false (or 0 depending on the wrapper version)
        publish_tf: false (if you don't want the camera to publish any related transforms for odom)
        publish_imu_tf: false (to stop IMU TF broadcasting)
        imu_fusion: false (to only use optical odometry if tracking is partially enabled, but setting pos_tracking_enabled to false should suffice) 

After modifying and saving the file, launch the camera node using the standard ROS launch command, and it will only publish the basic data topics, including: 

    rgb/image_rect_color (and other image topics)
    point_cloud/cloud_registered (the 3D colored point cloud)
